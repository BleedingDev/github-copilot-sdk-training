# Workshop Booking App Context

Tento soubor je syntetická workshopová instrukce. Nenahrazuje interní
workshopovou dokumentaci.

Pravidla:

- Sample Booking App je monorepo s PHP backendem a Next.js frontendem.
- MCP, Jira, Zephyr, Grafana a knowledge-base sync ber jako existující systémy.
- Nezakládej nové enterprise integrace, pokud to prompt výslovně nežádá.
- Při práci s Dev/QA/Docs lanes vždy udržuj oddělený ownership.
- Second-brain update smí obsahovat jen tvrzení podložená diffem, testy nebo existujícím kódem.
